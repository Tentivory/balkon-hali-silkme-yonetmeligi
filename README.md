# BALKON HALI SİLKME YÖNETMELİĞİ

## Resmi Statü

Bu depo, T.C. Balkon İşleri Genel Müdürlüğü tarafından **27 Eylül 2026** tarihinde yürürlüğe konulan *Ulusal Balkon Halı Silkme Usul ve Esasları Yönetmeliği*'nin referans uygulamasıdır.

Konu şakadır sanmayın. Komşunuzun üstüne düşen toz, ulusal bir meseledir.

## Amaç

1. Halıyı rastgele silkmeyi önlemek.
2. Silkme açısını 37 derece ile 52 derece arasında tutmak.
3. Pazar günü 11:00–13:00 arasını *sessiz balkon günü* ilan etmek.
4. Rüzgâr yönünü dikkate almayan vatandaşa idari ihtar üretmek.

## Kuruluş

```bash
python3 yonetmelik.py
```

Program sizden kat, rüzgâr ve niyet sorar. Cevabınıza göre ya izin verir ya da resmi bir yazı yazar.

## Örnek Çıktı

```
SAYI: 2026/BALKON-441
KONU: Halı silkme talebinizin reddi

İlgili talebiniz, aşağıdaki gerekçelerle uygun görülmemiştir:
- Rüzgâr komşu balkonuna doğrudur.
- Saat 12:07'dir ve Pazar sessizlik penceresi içindedir.
- Halının havı yönü beyan edilmemiştir.

Gereğini rica ederiz.
```

## Sık Sorulan Sorular

**Bu gerçek bir yasa mı?**  
Hayır. Ama balkonda halı silkmek gerçektir.

**Neden 37 derece?**  
Çünkü 36 çok gevşek, 53 çok kibirli duruyor.

**Siyasi bir mesaj var mı?**  
Yok. Kesinlikle yok. Dosyaların içine bakmayın.
